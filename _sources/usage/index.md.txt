## Keyboard Shortcuts

For the Annotation phase, some keyboard shortcuts are implemented.

- Left Arrow Key: Go backwards through the samples (sentences)
- Right Arrow Key: Go to the next sample (sentence)
- Enter Key: Can be used to saved the annotation (send the latest state of all labels to the server)

:::{note}
Custom keyboard shortcuts are now implemented. The selection of labels can be done with custom shortcuts that are set in the project-config.
:::
