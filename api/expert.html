Expert

This app is concerned with the expert phase of the annotation. The expert makes the final decision on each example and can edit the codebook along the way.

Models

class expert.models.CodebookDraft(*args, **kwargs)

Database table: expert_codebookdraft

An expert’s uncommitted codebook edit for one assignment.

The draft lives server-side from the moment the expert clicks Save in the codebook editor, so a reload, crash, or expired session never loses an edit. Committing the decision turns the draft into a git commit and deletes it; Undo deletes it directly.
