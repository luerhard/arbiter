Core

Core is the app that handles the initial url routing, the settings and the starting page. The idea is to keep this rather empty and to dispatch most of the logic to its specific apps.

Views

core.views.open_tasks(user) → list[dict]

The batches where the user has something to do right now.

Mixins

class core.mixins.RoleRequiredMixin

Project-level check against ProjectUser.default_role.

Use for project pages and for managing a project or its batches (create, export, change phase, delete).

The project comes from the URL alone, never from what the request sends along: an id in the query string or form would let a member of one project into another.

class core.mixins.BatchRoleRequiredMixin

Batch-level check against BatchUser.role.

Use for views where a user works on a batch (annotate, discuss, decide as expert). Roles are assigned per batch, so a project expert may annotate one batch, and project members who are not part of a batch get no access.
