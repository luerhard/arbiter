advance_from_annotation_if_finalized() → BatchPhase | None

Advance the batch once all annotators have finalized.

-> DISCUSSION when disagreements exist, otherwise straight to FINAL (no discussion or expert decisions needed) and the next batch starts. Returns the new phase, or None if nothing changed.

advance_from_discussion() → BatchPhase | None

Advance the batch once the discussion has ended.

-> EXPERT when disagreements remain after discussion, otherwise FINAL (no expert decisions needed) and the next batch starts. Returns the new phase, or None if nothing changed.

all_annotators_finalized() → bool

True if every annotator has confirmed they are done annotating.

disagreements(phase)

The examples the annotators have not agreed on in this phase: different labels, or someone has not saved theirs yet. Normally everyone has saved before the batch moves on; when an expert moves it on by hand earlier, a missing label must not count as “no labels”, which would turn it into an agreement nobody made.

discussion_examples()

The examples to discuss, in batch order: the disagreements as they were when the batch entered the discussion, i.e. the examples with DISCUSSION assignments. Unlike disagreements(), this does not change when labels change afterwards.
